# ranking service

**Владелец:** участник 4
**Назначение:** ранжирование: поиск, скоринг, объяснение релевантности

## Структура

- `app/` — исходный код FastAPI-приложения
- `tests/` — юнит- и интеграционные тесты (запуск: `uv run pytest services/ranking`)
- `Dockerfile` — образ сервиса

## Контракты

Модели и ошибки берутся из `contracts/schemas/`; спецификация — `contracts/openapi.yaml`.
