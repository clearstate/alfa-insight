# ingestion service

**Владелец:** участник 2
**Назначение:** ингестия: парсеры новостей, разбор PDF аналитики, нормализация, дедупликация

## Структура

- `app/` — исходный код FastAPI-приложения
- `tests/` — юнит- и интеграционные тесты (запуск: `uv run pytest services/ingestion`)
- `Dockerfile` — образ сервиса

## Контракты

Модели и ошибки берутся из `contracts/schemas/`; спецификация — `contracts/openapi.yaml`.
