# profile service

**Владелец:** участник 1
**Назначение:** профиль компании: загрузка CSV, признаки, граф связей, полнота данных

## Структура

- `app/` — исходный код FastAPI-приложения
- `tests/` — юнит- и интеграционные тесты (запуск: `uv run pytest services/profile`)
- `Dockerfile` — образ сервиса

## Контракты

Модели и ошибки берутся из `contracts/schemas/`; спецификация — `contracts/openapi.yaml`.
