# agent service

**Владелец:** участник 3
**Назначение:** планировщик → инструменты → синтез → самопроверка, с трассой исполнения.

## Структура

- `app/` — код агента
- `prompts/` — версионируемые промпты (plan, synth, critic, followup)
- `config/` — маршрутизация моделей, лимиты токенов, пороги, правила чувствительностей
- `tests/` — тесты на заглушках LLM (детерминированные)
