# api service

**Владелец:** участник 6
**Назначение:** шлюз: авторизация, права доступа, корреляция запросов, агрегация ответов

## Структура

- `app/` — исходный код FastAPI-приложения
- `tests/` — юнит- и интеграционные тесты (запуск: `uv run pytest services/api`)
- `Dockerfile` — образ сервиса

## Контракты

Модели и ошибки берутся из `contracts/schemas/`; спецификация — `contracts/openapi.yaml`.
