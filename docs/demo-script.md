# Сценарий демо для защиты

**Длительность:** 7–8 минут. **Подготовка:** `.env` заполнен, `make up`, `make seed` выполнены.

## До начала

- [ ] Контейнеры подняты, лента демо-клиента загружена (без ожидания LLM на сцене).
- [ ] Открыты: интерфейс, терминал, вкладка `docs/quality-metrics.md`.
- [ ] Заготовлен «плохой» пример (инсайт с пониженной уверенностью) — показать, что система честна.

## Типичные вопросы жюри

- *Откуда берутся данные?* — `data/README.md`; исходные данные не коммитятся.
- *Как отличить фразу модели от факта?* — `claim_type` + `provenance` + критик.
- *Что при недоступности LLM?* — типизированная ошибка, деградация ранжирования без LLM.
- *Риск prompt injection из новостей?* — белый список инструментов, данные изолированы, критик, тест.
- *Что не работает?* — честно: см. «Что измерено, а что нет» в `quality-metrics.md`.
