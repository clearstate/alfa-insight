# Безопасная работа AI-компонентов (прототип)

| Механизм | Реализация | Где |
|---|---|---|
| Разграничение прав | Пользователь видит только свои `company_ids` (403 иначе); токен HMAC-SHA256 с TTL 12 ч; проверка полномочий внутри банка считается выполненной при входе (вопрос 32 вебинара) | `people.py`, `server.py` |
| Минимизация данных для LLM | В промпт попадает `prompt_view`: без идентификаторов компании, контрагентов и физлиц, выручка — порядок величины; `NEGATIVEMARK` не выдаётся | `company_profile/prompt_view.py`, `agent.py` |
| Недоверенные тексты | Новости передаются в `<document>…</document>` с инструкцией не выполнять команды; материалы с `prompt_injection_suspected` не анализируются, не попадают в ленту, прямой запрос возвращает `status=blocked` | `agent.py`, `kb.py`, `llm.py` |
| Контроль инструментов | Белый список инструментов, все — только чтение; единственная запись — журналы обратной связи/заявок | `agent.py` |
| Журналирование | `data/runtime/audit.jsonl`: пользователь, действие, компания, роль, материал; тексты и профили в журнал не пишутся. Трассировка каждого разбора — в ответе API | `runtime.py` |
| Ограничения на опасные действия | Нет исполняемых действий от имени клиента: «связаться с менеджером» и «заявка» только регистрируют обращение (демо) | `server.py` |
| Контроль выхода модели | Строгий разбор JSON; проверка чисел и атрибуции позиции банка; откат на шаблон; разрешены только модели из Приложения 3; дневной бюджет токенов | `llm.py`, `agent.py` |
| Загрузка новостей по URL | SSRF-защита, robots.txt, лимиты размера и редиректов, белый список доменов (участник 2) | `news_ingest/fetcher.py` |
| Защита API | Лимит 240 запросов/мин на пользователя, тело ≤ 64 КБ, `X-Content-Type-Options`, безопасная раздача файлов (без выхода из каталога) | `server.py` |
| Секреты | Только переменные окружения/`.env` (в `.gitignore`) | `.env.example` |

Не сделано (вне периметра прототипа): реальная аутентификация и SSO банка, TLS (ставится reverse-proxy), WAF, DNS-rebinding-защита ingest (нужен egress-прокси), шифрование журналов.
