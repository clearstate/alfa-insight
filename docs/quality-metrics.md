# Метрики качества

## Что измеряем

| Метрика | Определение | Как считается |
|---|---|---|
| Precision@k / Recall@k | релевантность ленты по разметке `data/eval/` | `scripts/run_eval.py` |
| Точность claim_type | доля утверждений с верным типом | ручная разметка выборки |
| Доля утверждений с провенансом | `claims` с непустым `provenance` / все `claims` | автоматически |
| Покрытие фрагментов | доля `fact`-claims, чей фрагмент реально есть в источнике | автоматически |
| Прохождение критиком | доля прогонов с `critic_passed=true` | из `RunTrace` |
| Калибровка уверенности | соответствие `confidence` фактической точности | сравнение по бинам |
| Латентность | время от запроса до инсайта | из `RunTrace.total_duration_ms` |
| Стоимость | токены на инсайт | из логов LLM |

## Процесс мониторинга

1. PR, меняющий ранжирование, промпты или модель, **обязан** приложить отчёт `make eval`.
2. Еженедельно — прогон eval на фиксированном наборе; отклонение метрик > 5 п.п. — разбор.
3. Прод-мониторинг: доля `critic_passed=false`, латентность, стоимость.
4. Каждый инцидент качества (неверный инсайт) → кейс в `data/eval/`.
