# Тестовые сценарии

## Контрактные (`tests/contract/`)

- Примеры из `contracts/examples/` валидируются всеми Pydantic-моделями.
- `contracts/openapi.yaml` проходит `openapi-spec-validator`.
- Каждый сервис отвечает в формате `contracts/` (проверяется в CI).

## Юнит / интеграционные (`services/*/tests/`)

| Сервис | Сценарии |
|---|---|
| profile | загрузка CSV с пропусками → корректная `completeness` и `missing_fields`; построение графа связей |
| ingestion | парсинг новостной страницы; разбор PDF; нормализация дат; дедупликация дублей |
| ranking | событие из отрасли клиента получает высокий скор; объяснение содержит сработавшие признаки |
| agent | успешный прогон; провал критика → ревизия; claim без провенанса отклонён; prompt injection в тексте игнорируется |
| api | 401 без токена; 403 на чужого клиента; `request_id` в ответе и в заголовке |

## E2E (`tests/e2e/`, Playwright)

1. Вход с неверными данными → сообщение об ошибке.
2. Вход → главный экран → выбор клиента.
3. Лента → открытие первого события → карточка инсайта с метками `claim_type`.
4. Раскрытие трассы → ≥ 3 шага.
5. Чип вопроса → ответ со ссылками на источники.
6. Смена клиента → лента перестроена (другой первый элемент).
